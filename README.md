## Deploy on GitHub Pages
1. Create a new GitHub repository (e.g. `portfolio`).
2. Upload all files (`index.html`, `style.css`, `script.js`, `assets/`).
3. Go to **Settings → Pages**.
4. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
5. Your site goes live at `https://your-username.github.io/portfolio/`.

No build step required — it's pure static HTML/CSS/JS.
